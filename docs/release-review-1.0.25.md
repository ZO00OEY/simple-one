# Simple One 1.0.25 发布复核

本版以 1.0.24 的功能集为基线，更新中英文文档、隐私说明及发布版本信息。没有新增功能或更改个人配置格式。

## 复核范围

- 按单人笔记库、电脑与手机跨设备使用的负载，复核 Token 保存、读回验证、明文迁移、恢复副本及部分写入失败保护。
- 核对轻量同步的 Secret Storage 引用、本机设备状态、共享配置、分享授权与 GitHub CLI 的边界。检查过程只报告是否存在凭据，不输出密钥值。
- 运行 `npm run check`：生产依赖审计、零警告 ESLint、CSS、完整回归测试、TypeScript 和生产构建。
- 使用独立公开仓库检出与明确的文件清单，只导出源码、文档、测试和标准产物；排除个人配置、凭据、日志、同步基线、分享清单及自定义模板。
- 核对三个 Release 附件的版本、字节数和 SHA-256，确保与验证后的本地产物一致。

2026-10-27：完整 `npm run check` 通过，生产依赖审计为 0 个已知漏洞。复核范围内未发现阻塞本版发布的问题；公开导出未发现私人配置文件或当前已知凭据的匹配内容。

## 保护边界

Obsidian 1.11.4+ 支持 Secret Storage 迁移；更旧版本仍沿用原来的轻量同步本机 JSON 保存方式。历史备份、旧插件文件与 Git 历史不自动清除。Secret Storage 不用于防御恶意插件或已被控制的本机。

不执行用户私人笔记库中的真实批量删除、移动、覆盖式同步或公开笔记发布。真实 Android／iOS 触控、最低版本和所有第三方主题组合不属于完整实机验证范围。通过自动检查不等于不存在任何缺陷。

详细文件分类见[个人配置与凭据](private-files.md)。
