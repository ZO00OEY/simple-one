# 1.0.35 发布核验

- 全项目 `npm run check` 通过：生产依赖审计、宿主与 AI 代码检查、CSS 检查、完整回归及生产构建。
- 标签重命名读取 frontmatter 时先检查类型；菜单接管明确保留原方法身份，通过回归确认调用接收者及卸载恢复。
- AI 模型返回按字段校验，评价身份和配置基线由本地构造；历史存储损坏时尝试备份，拒绝把坏集合当作空数据保存。
- AI 控件样式复用宿主，清理无效与重复规则，保留必要的主题覆盖；新增模型选择、悬停、禁用、危险操作及窄屏规则回归。
- 重复构建产物一致；插件重载后未捕获运行错误。未进行真实付费模型请求或手机真机视觉验收。
- 发布候选文件检查未发现密钥格式或本机绝对路径，并核对本机私人同步配置中的作者、仓库及凭据值没有进入候选文件。
- Release 仅包含 `main.js`、`manifest.json`、`styles.css`。个人设置、聊天、凭据、同步状态及日志不纳入公开源码和发布附件。

社区对 1.0.35 的自动审核结果应以该版本实际扫描为准；本记录不声称官网已批准或所有警告清零。
