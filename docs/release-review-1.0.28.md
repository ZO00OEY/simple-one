# Simple One 1.0.28 验收范围

- 浮动编辑工具栏：主题样式预览、原生格式切换、自定义文字/高亮配色、收藏颜色管理、标题/引用预设记忆、选区局部格式清理。
- 编辑工具栏按钮显隐与排序：键盘、鼠标与触屏命中测试；拖动预览、取消、失焦和卸载恢复光标。
- 搜索工具箱：选中文字在笔记库或网页中搜索。
- 可选 Simple AI 联动：仅在已启用且有模型时显示翻译入口；独立选择模型、提示词与互译语言；不复制 API 凭据。
- 自然段译文采用编号校验，由插件保留原文并交错拼排；预览后一次插入，可撤销。笔记内容变化、插件禁用、返回缺段/重复编号/不完整时不写入。
- 代码格式保护覆盖反引号/波浪号围栏和行内代码；重复配色不重复转义 `&`。
- 保留主库近期的调色盘、收藏管理和浅色侧栏背景设置改进。

发布检查：完整 lint、功能测试、生产依赖审计、TypeScript 与生产构建；两个插件在主库重载并核对版本。测试使用模拟 API，不产生付费翻译调用。用户此前已多轮截图确认桌面布局；本次未新增截图验收，未做真实模型翻译或真机触屏验收。

公开发布仅包含插件源码及标准安装文件。私人配置、模型来源目录、API 密钥、聊天记录、分享清单与测试笔记不纳入公开仓库和 release 附件。
