# Simple One 1.0.24 发布核对

本版整合已确认的界面改动、公共设置与附件组件、共享流程图观看组件，以及轻量同步 Token 的 Secret Storage 迁移。

## 发布文件与边界

- Release 仅上传 `main.js`、`manifest.json`、`styles.css`；版本标签与 manifest、package 和 versions 映射一致。
- 公开源码使用独立发布检出，以明确的源码、脚本、文档及标准产物清单复制；不复制整个插件目录。
- `data.json*`、同步设置与本机状态、日志、分享清单、授权记录和自定义模板均不进入公开仓库。
- 个人笔记库配置保持原位。Secret Storage 迁移只处理当前轻量同步 Token，不修改同步基线、缓存或笔记正文。

## 验证项目

发布检查入口为 `npm run check`：生产依赖审计、零警告 ESLint、CSS 检查、完整回归测试和 TypeScript／生产构建。

2026-10-27：上述完整检查通过；生产依赖审计为 0 个已知漏洞。公开导出另外检查个人文件名、常见凭据格式及本机已存凭据匹配，不输出凭据值。

回归覆盖附件选择与确认、失败恢复、过期笔记保护、流程图缩放与拖动、全屏位置恢复、切换笔记和卸载清理、三文件离线安装、模板保留、同步与发布恢复，以及 Token 迁移、恢复副本清理和部分写入失败。

## 已知限制

- 基础最低版本仍为 Obsidian 1.7.2；Secret Storage 需要 1.11.4+。旧版本轻量同步仍使用本机 JSON，不应公开或发送这些文件。
- 旧备份、旧插件目录、其他设备和 Git 历史中的凭据副本不会自动移除；需要时由用户自行撤销旧 Token 和处理历史。
- 分享网站需重新发布更新的默认模板；已有自定义 HTML 不会被强制覆盖。
- 设置界面仍以中文为主。真实 Android／iOS 触控、不同主题、多窗口和最低版本兼容未做完整实机矩阵验证。
- 不在用户私人笔记库执行真实批量删除、附件移动或覆盖式同步测试。

凭据文件的具体用途见[个人配置与凭据](private-files.md)。
