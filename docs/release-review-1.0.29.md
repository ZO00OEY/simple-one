# Simple One 1.0.29 验收记录

## 版本范围

- 流式翻译预览、可编辑标记卡片、原文重译与转文字。
- 分享库单选下拉、复制／链接开关、渠道选择、快捷打开网页、刷新与独立分享日志入口。
- GitHub Pages／EdgeOne 双平台部署检查、完成摘要、推送与检查时间、变更数量及可选阶段耗时。
- 紧凑分享阅读器设置、自定义格式颜色、翻译卡片及代码／引用／Callout 的快捷复制。
- 字体与中英间距默认值、附件引用与整理、段落链接、同步恢复与排除规则。

## 发布检查

执行生产依赖审计、严格 ESLint／CSS 检查、完整功能回归、额外英文字间距检查和 TypeScript／生产构建。回归包含发布输入保护、HTML 清理、附件索引与引用保护、桌面与轻量同步、分享上传与部署状态、模板阅读器和翻译生命周期。

使用模拟服务测试，不调用真实模型，不修改用户的同步仓库，不替用户发布笔记网站。本轮没有新增截图验收，也未覆盖全部手机设备、主题组合与真实托管平台的端到端部署。

## 公开内容与升级

公开仓库仅提交插件源码、测试、文档和构建产物。上传前检查候选清单与已跟踪文件，不纳入个人配置、凭据、同步日志、本机基线、分享清单、分享库关联、自定义模板或临时输出。

Release 安装附件仅为 `main.js`、`manifest.json`、`styles.css`。保留本机 `data.json` 等个人文件；升级仅替换三个安装文件。默认阅读器和依赖许可证已嵌入插件，无需额外下载。

已有分享网站需使用新版默认模板并重新推送，才能获得阅读器变更。用户保存的自定义模板不会自动被覆盖。
