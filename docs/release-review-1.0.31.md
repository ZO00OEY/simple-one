# 1.0.31 发布核验

- 根项目 `npm run check` 通过，包含生产依赖审计、宿主 ESLint/CSS 规范、完整原有回归、内置 AI 测试及严格 TypeScript 生产构建。生产依赖审计为 0 个漏洞。
- AI 源码保留为 `modules/ai`，生产构建直接打包，不依赖安装独立 Simple AI；宿主编译同时检查模块。模块原有样式作用域和布局规则予以保留，整份样式进行语法检查。
- 新增 AI 生命周期测试，验证默认关闭、启停清理、配置保存失败回滚、启动失败清理和最低版本守卫；启用时不读取或复制旧插件文件。
- 设置 DOM 测试验证六组顺序、移除基础／高级切换、Skills 库无额外说明、子页返回及渲染不触发配置写入。
- AI 原有模拟回归通过，覆盖协议、密钥、Agent 工具、记忆、压缩、停止、用量和选区翻译；新增内置翻译路由回归。
- 在 Obsidian 中重载后未捕获运行错误，实际设置分组与启用状态正确，私人配置可持久保存。
- 生产 `main.js` 约 4.04 MB，低于构建中保留的 5 MB 单文件保护；标准安装仍只需 `main.js`、`manifest.json`、`styles.css`。
- 发布清单排除 `data.json`、私有 AI 目录、聊天、缓存、密钥及一次性迁移脚本。

限制：模拟测试不验证第三方真实模型服务的可用性和计费；未进行手机真机视觉验收。私人数据的本机一次性迁移不包含在插件功能或 Release 中。
