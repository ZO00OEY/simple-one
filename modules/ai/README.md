# 内置 AI 模块

从 Simple AI 的已验证实现迁入，随 Simple One 打包，无需另装插件。源码与模拟测试集中保留，方便核对原有模型、Agent、聊天、记忆及用量行为。

宿主入口是 `src/features/ai.ts`（需要 Obsidian 1.11.4+）。请求服务与聊天界面分离：启用 AI 才注册聊天界面、笔记事件和后台任务；关闭后仍可通过同一模型目录、密钥和用量记录进行手动翻译。设置不再分基础／高级页；模型来源随宿主配置保存，聊天与本机偏好位于私有目录，密钥使用独立命名空间。不包含自动读取或迁移独立 Simple AI 数据的逻辑。

设置项、按钮、复选框、分组外框和悬浮说明统一使用宿主 `src/shared/` 的实现。普通下拉框直接使用 Obsidian 控件；设置项说明通过 `setDesc` 写入原生悬浮提示，不额外占一行。

从 Simple One 目录运行 `npm run test:ai`，或单独 `npm test --prefix modules/ai`。根构建执行严格 TypeScript 检查并将本模块打入 `main.js`；样式在构建时合入 `styles.css`，保留模块已有的作用域和布局规则。

## AI 记忆与考官

工作记忆与考官默认关闭，按需在 AI 设置中启用。用户手写的工作约定优先于历史记忆；当前明确要求优先，不会被自动提取或考官修改。

一轮回复结束且工具调用全部结束后，主模型可提出最多 3 条长期偏好、纠正或身份事实；明确的“以后都这样”“记住”等表达也会触发校验。记忆模型校验用户原话、去重和处理冲突；普通一次性任务不会被当成长期偏好。没有触发词和候选时不调用记忆模型。闲时整理保留为补漏，默认每批最多处理 16 个会话，原有摘要分段断点只用于这个补漏路径。

记忆文件 SIMPLE_AI.md 的自动区域保存可读的逐条记忆，标记外的手写内容保留。旧会话摘要和旧自动区域散文会保留为待确认条目；原摘要仍保留作迁移来源。每条可查看来源、编辑并确认、置顶、忘掉和撤销；新纠正会废弃旧条目并留下取代原因。首次出现通常为低置信度，独立会话重复后升为中，明确确认后升为高。

每次请求只带最多 10 条核心记忆（置顶条目及高置信度的长期规则，正文预算 4000 字符），再按最近用户任务、会话目录、参考文件路径及关键词匹配最多 8 条相关记忆；两段条目正文合计不超过 6000 字符。无匹配不强塞，末尾注明已注入与未注入数量（不计已废弃条目）。手写区域另保留最多 2000 字符参考，超出注明截断；完整文件仍可查看和编辑。默认超过 30 天没有再次证实的生效条目会标为 stale，注入时显示“待确认”，不会删除；检索命中本身不算确认。用户再次表达或编辑确认后刷新日期并恢复生效，明确否定则废弃。

考官按来源、模型、角色和任务类型保存实测附注，记录样本数、成功/失败/中断、耗时、问题、日期与验收依据；不会混入用户记忆或改写候选用途说明。主模型选择子 Agent 时同时看到用户用途原文和实测附注。少于 3 个独立任务样本时只给低置信度，不允许据此切换模型；达到样本要求且结论一致后，仍需用户点击应用建议，并核对配置基线。用户反馈优先于考官推断，验收期间会话或配置变化则丢弃结果。

### 存储与回归说明

SIMPLE_AI.md 是条目正文的真相来源；private/state.json 只保存索引、旧 summaries、迁移状态与撤销记录，private/work.json 的 assessments/observations 和 capabilities 保存独立的能力附注。这些是运行时路径，本次开发不读取或改写实际私人文件。maxAgeDays 默认 30，在构造记忆上下文时按 lastConfirmedAt 持久化 active → stale；batch 默认 16，在过滤已忘来源后限制每次整理的会话数，参考文件提取另算。检索不会刷新确认日期。并发手动修改时，预期正文不匹配会拒绝写入。

回归覆盖：test-atomic-memory.mjs 验证迁移、去重冲突、忘掉/撤销、检索与过期；test-agent.mjs 验证上下文、批次、密钥脱敏和真实运行时接入；test-cooperation-validation.mjs 验证样本门槛、用户反馈和配置变化丢弃；test-storage-schema.mjs 与 test-persistence.mjs 验证损坏文件备份恢复和双份损坏拒绝覆盖。全部使用模拟数据，无真实模型调用。
