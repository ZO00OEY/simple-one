# Simple One

[English](README.md) | 简体中文

Simple One 是一套按需启用的 Obsidian 工具，涵盖笔记同步、网页分享、日程、AI，以及编辑、附件、显示和主题设置。可以只使用其中一部分，不必开启全部功能。设置界面目前以中文为主。

[下载最新版](https://github.com/ZO00OEY/simple-one/releases/latest) · [使用说明](USAGE.zh-CN.md) · [更新记录](RELEASE_NOTES.md) · [反馈问题](https://github.com/ZO00OEY/simple-one/issues)

## 功能概览

| 分类 | 可以做什么 |
| --- | --- |
| 同步 | 电脑端使用原生 Git 同步笔记库；手机端或未安装 Git 的电脑可使用 GitHub API 轻量同步，提供变更预览、冲突处理和下载恢复。 |
| 分享 | 以独立 GitHub 仓库为基础，将选定笔记及附件发布为可直接打开的 HTML 网页链接，支持 GitHub Pages 和可选的 EdgeOne 托管。 |
| 日程 | 集中管理日历、日记、待办结转、周期提醒、纪念日和年度节假日安排。 |
| AI | 在笔记库中使用 AI 聊天、模型管理、笔记工具、skills 和模型协作，可选启用工作记忆与能力评估。 |
| 拓展 | 管理同步、分享、日程和 AI 入口，并提供搜索目录过滤、快速建笔记及附件命名、存放、引用查找和清理等工具。 |
| 编辑 | 提供浮动工具栏、彩色格式、选区翻译、正文整理、粘贴链接处理和双列编辑等快捷操作。 |
| 显示 | 分别调整电脑与手机的显示参数，增强 HTML、图片、流程图和颜色代码的查看体验。 |
| 主题 | 调整强调色、正文与标题的字体、字号、颜色和间距，以及引用、Callout 等格式的外观。 |

## 主要功能

### 同步：在电脑与手机间使用同一笔记库

- **电脑端完整 Git**：通过本地 Git 保存提交、检查云端更新、合并和推送，支持自动同步与冲突处理。需要安装 Git，并通过 GitHub CLI 授权。
- **轻量同步**：通过 GitHub API 同步，无需本地 Git，可用于 Android、iOS 和电脑。支持查看文件差异、核对同步范围、处理删除与冲突，以及恢复中断的下载。
- **同步侧栏**：查看状态与变更文件，切换列表或目录树；文件多时分页显示，长错误日志默认显示前 10 行，可展开查看。

各设备分别选择适合自己的同步方式。首次同步前检查范围与预览，避免多个同步工具同时修改同一笔记库；重要内容保留独立备份。

### 分享：给别人一个能直接阅读的网页链接

将想公开的笔记加入分享列表，发布到独立的 GitHub 分享仓库，再通过网页链接供别人阅读，无需安装 Obsidian。

- 分享笔记及引用附件，支持公开名称、目录和稳定链接。
- 使用 GitHub Pages，或按需关联 EdgeOne；侧栏提供发布、刷新、部署状态、日志、复制链接和打开网页等操作。
- 内置 HTML 阅读器，提供文件导航、文章目录、日夜模式、颜色与排版设置；也可以使用自定义 HTML 模板。
- 分享与私人笔记库同步分开配置，可以管理多个分享库。

分享内容会公开访问。发布前检查正文与附件；撤下分享不会清除 Git 历史、缓存或他人保存的副本。网页效果可能与 Obsidian 中的主题或插件渲染不同。

### 日程：把日记、任务和提醒放在一起

从日历查看日期、打开或创建日记，配置日记目录和模板，结转未完成任务；设置周期事项、纪念日、当日或提前提醒，并管理每年的节假日与调休安排。

### AI：围绕笔记进行对话与辅助处理

内置 AI 聊天和模型设置，无需另装独立 AI 插件。统一管理接口、模型、助手和用量，配合笔记上下文、工具、skills 与模型协作完成任务。

可选的工作记忆支持来源查看、编辑、忘掉和撤销；能力评估记录模型表现，供选择协作模型时参考，应用配置建议仍需用户确认。这两项默认关闭。

编辑工具栏的翻译复用同一模型列表，可以单独选择模型、语言和提示词；关闭 AI 聊天界面后仍可手动翻译。使用 AI 或翻译时，相关文字和上下文会发送到你配置的模型服务。

### 拓展：搜索、网页采集与附件整理

- **功能入口**：按需启用同步、分享、日程和 AI。
- **搜索增强**：过滤不需要搜索的目录，从选中文字搜索笔记库或网页。
- **快速建笔记**：按网站规则提取标题、作者和正文等字段，填入模板；支持网址采集、部分站点搜索，以及规则导入、导出和测试。
- **附件优化**：检查附件存放方式，整理图片和其他附件的名称与目录，提取内嵌图片，查找引用笔记，扫描和清理未引用附件；部分整理可自动运行。
- **笔记辅助**：新笔记属性补齐、标签重命名、笔记链接及路径快捷复制等。

网页采集受网站结构、访问限制和规则影响，部分渲染抓取依赖桌面能力。附件批量操作前应检查清单；自动清理默认关闭，启用后会核对引用并等待稳定后再处理。

### 编辑：把常用操作放到手边

- **浮动工具栏**：选中文字后直接设置多种文字格式与颜色，进行搜索、翻译等操作，并调整按钮显隐与顺序。它是日常编辑工具箱，不只是一个格式按钮。
- **标题、引用与 Callout**：快速应用或转换格式，配合自定义颜色和样式整理内容。
- **翻译预览**：按段查看原文与译文，确认后插入普通文字或翻译卡片；卡片支持编辑、重新翻译和转为文字。
- **正文与粘贴整理**：按规则处理空格、换行和序号；粘贴网址时抓取并清理标题，转换普通链接或 Obsidian 内部链接。
- **双列显示**：并排编排和编辑内容，支持右键、手势与快捷键入口，并可扩展到最多四列。

### 显示：适配不同屏幕与内容

- 电脑与手机分别保存显示参数，例如正文宽度、图片高度和弹出窗口比例；手机另有顶部按钮、紧凑底栏等调整。
- **桌面端**可在正文空间不足时自动收起右侧栏，之后仍可手动展开；该选项不在手机端重复提供。
- 将 HTML 代码块渲染为预览，不执行内嵌脚本；支持仅影响显示、不改原文的文本替换规则。
- 图片点击放大与缩放，Mermaid 流程图适应宽度、拖动、缩放与全屏查看，以及颜色代码预览。

### 主题：集中调整笔记外观

便捷设置主题强调色；调整正文、标题及不同格式的字体、字号、颜色、行高、字间距和段间距。引用与 Callout 可单独设置外观，并支持自定义 Callout。按需启用各项覆盖，关闭的项目跟随 Obsidian 或当前主题。

## 安装与更新

1. 从同一个 [Release](https://github.com/ZO00OEY/simple-one/releases/latest) 下载 **main.js、manifest.json、styles.css**。
2. 放入笔记库的 `.obsidian/plugins/simple-one/`；使用自定义配置目录时替换对应路径。
3. 在 Obsidian 社区插件中启用 **Simple One**，进入 **设置 → Simple One** 按需开启功能。

更新时替换这三个文件并重载插件即可。保留个人配置与自定义模板，不要删除整个插件目录。默认分享阅读器已内置，无需额外下载 HTML。

| 环境 | 要求 |
| --- | --- |
| 基础功能 | Obsidian 1.7.2 或更高版本；支持桌面和移动端，部分功能有平台限制。 |
| 内置 AI、翻译及使用 Secret Storage 的分享授权 | Obsidian 1.11.4 或更高版本，并配置相应服务。 |
| 完整 Git 同步 | 桌面端、Git 和 GitHub CLI 授权。 |
| GitHub API 轻量同步 | GitHub 仓库及具有相应权限的 Token，无需本地 Git。 |

## 数据与权限

插件不包含遥测统计。网页采集访问目标网站；同步、分享及 AI 使用你配置的服务。本地日记、编辑和附件工具会读写笔记库，复制操作使用剪贴板，桌面 Git 会运行本地命令。

个人设置、凭据、聊天、同步状态、日志和私人分享记录不包含在公开源码或 Release 附件中。源码仓库的忽略规则与私人笔记库的同步规则用途不同。详情见[个人配置与凭据](docs/private-files.md)。

## 开发与反馈

使用 Node.js 22（仓库固定版本见 `.node-version`）：

```sh
npm ci
npm run check
```

`npm run dev` 监听构建，`npm run build` 生成发布文件，`npm run build:verify` 验证干净重复构建的一致性。详见 [CONTRIBUTING.md](CONTRIBUTING.md)。

反馈时请提供系统、Obsidian 版本、主题和复现步骤，并使用脱敏示例。自动测试不能替代所有手机、主题及真实服务的验证。
