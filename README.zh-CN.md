# Simple One

[English](README.md) | 简体中文

**把写作、整理、日记、同步与公开分享，放进一套按需启用的 Obsidian 工具。**

整理笔记、从网页生成阅读记录、查看日历与待办，或在电脑和手机间同步笔记。Simple One 将这些日常操作集中起来，各项功能按需配置，电脑和手机的显示参数可以分别保存。设置界面目前以中文为主。

[下载最新版](https://github.com/ZO00OEY/simple-one/releases/latest) · [使用说明](USAGE.zh-CN.md) · [更新记录](RELEASE_NOTES.md) · [问题反馈](https://github.com/ZO00OEY/simple-one/issues)

## 可以做什么

| 场景 | 功能 |
| --- | --- |
| 写作与整理 | 标题、引用、Callout 快捷操作；按规则整理正文；粘贴网址自动提取标题、清洗链接。 |
| 网页转笔记 | 按模板提取网站字段，用网址或站点搜索生成笔记；管理、导入、导出并测试网站规则。 |
| 日历与日记 | 日期导航、日记模板、未完成任务结转、待提醒事件、纪念日和年度假期安排。 |
| 阅读与显示 | 正文宽度、图片大小、双列显示、图片放大，以及 HTML、颜色与图表预览。 |
| 笔记与附件管理 | 新笔记属性补齐、搜索目录筛选、附件扫描与整理。 |
| 笔记库同步 | 电脑端原生 Git，或适合手机及无 Git 电脑的轻量 GitHub API 同步；差异预览、冲突处理与中断恢复。 |
| 公开分享 | 选择笔记发布到独立分享库；固定链接、公开目录与名称管理、HTML 模板及可选 EdgeOne 托管。 |

网页采集效果取决于目标网站的页面结构、访问限制和规则配置。部分页面渲染能力依赖电脑端环境。分享网站的外观可能与 Obsidian 内不同。

## 安装与更新

1. 从 [Releases](https://github.com/ZO00OEY/simple-one/releases) 下载同一版本的 **main.js、manifest.json、styles.css**。
2. 将三个文件放入笔记库的 `.obsidian/plugins/simple-one/`。使用自定义配置目录时，替换 `.obsidian`。
3. 在 Obsidian 的第三方插件设置中启用 **Simple One**。

更新时替换这三个文件并重载插件即可。保留原有个人配置，不必删除插件目录。默认分享阅读器与许可证已内置，无需单独下载 HTML。

基础插件最低要求 **Obsidian 1.7.2**。使用 Secret Storage 的 Token 分享授权与 EdgeOne 授权需要 **1.11.4 或以上**。电脑端原生同步还需要安装 Git；授权细节见使用说明。

## 从哪里开始

打开 **设置 → Simple One**：

- **显示、主题**：调整笔记阅读和编辑外观。
- **编辑**：配置顶部快捷功能、编辑优化、粘贴处理及双列显示。自动排版、快速新建笔记和文本显示替换通过行尾齿轮进入详细设置。
- **拓展**：控制同步、分享和日程入口，配置搜索目录筛选与附件工具。
- **日程**：配置日记、日历、待提醒事件、纪念日和年度假期安排。
- **同步、分享**：两个独立标签页，分别配置私人笔记库同步和公开笔记分享。

建议先启用自己需要的功能，再逐步配置其他工具。设置说明通常可通过鼠标悬停查看。

## 如何选择同步方式

| 方式 | 适用设备 | 特点 |
| --- | --- | --- |
| 电脑端 Git | 安装 Git 的电脑 | 本机 Git 仓库、提交历史、自动备份与云端更新。 |
| 轻量 Git 同步 | Android、iOS、电脑 | 使用 GitHub API，不需要本机 Git；支持文件差异、同步范围和下载恢复。 |
| 公开笔记分享 | 电脑、手机 | 发布选中的笔记供他人阅读，与私人笔记库同步分别配置。 |

同一设备选择一种笔记库同步方式。不要让多个同步工具同时写入同一笔记库。首次接入、删除和冲突处理时，先检查预览；使用同步或批量附件操作前，应保留独立备份。

## 权限与隐私

- **没有遥测**。网页采集访问指定网站；GitHub 同步与分享访问相应服务；EdgeOne 为可选接入。
- **同步需要授权**。Token、运行状态和凭据属于本机数据，不应提交到公共仓库，也不要随问题报告上传整个配置文件。
- **分享就是公开发布**。选中的笔记和引用附件可被访问；撤下分享不会清除 Git 历史、缓存或他人副本。正文和普通外部链接不会自动脱敏，发布前检查私人信息。
- **本机工具需要文件权限**。同步、日记与附件工具会读写相关笔记库文件；复制功能使用剪贴板；电脑端 Git 执行本机命令。
- **项目与个人笔记库分开管理**。插件独立源码仓库排除个人配置、凭据、日志、同步状态、分享清单和自定义模板。私人笔记库中的配置同步策略另行管理，不能把源码仓库的忽略规则直接当作整库规则。

详情见[使用说明](USAGE.zh-CN.md)、[个人配置与凭据说明](docs/private-files.md)与[技术审核说明](docs/automated-review-notes.md)。

## 1.0.24 的重点

本版统一设置分组、复选框图标、按钮和附件操作栏，合并附件归位流程，清理失效设置及旧样式。插件与默认分享阅读器共用流程图观看组件，支持画布模式、拖动平移、滚轮缩放、适应宽度和全屏。分享页支持笔记中保存的双列比例，窄屏自动转为单列；编辑时的分列拖拽不会带到公开页面。

设置界面仍以中文为主，中英文介绍与使用说明同时维护。升级时保留个人配置与自定义模板；已有分享网站需重新推送，并使用本版默认阅读器才会获得新交互。

详细范围和验证限制见[发行说明](RELEASE_NOTES.md)及[本轮审查记录](docs/release-review-1.0.24.md)。这不代表所有网站规则、设备或第三方主题组合均已验证。

## 开发与反馈

使用 Node.js 22：

```sh
npm ci
npm run check
```

`npm run dev` 启动开发构建；`npm run build` 生成发布产物。构建包含 TypeScript 严格检查和未使用代码检查，完整检查还包含生产依赖安全审计、ESLint/CSS 与回归测试。

独立源码仓库中的安装脚本会生成缺失的本机忽略规则，并保留已有规则。请参阅 [CONTRIBUTING.md](CONTRIBUTING.md)。

欢迎通过 [Issues](https://github.com/ZO00OEY/simple-one/issues) 提交可复现步骤、系统与 Obsidian 版本；请使用脱敏示例。
