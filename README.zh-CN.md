# Simple One

[English](README.md) | 中文介绍 | [English user guide](USAGE.md) | [中文使用说明](USAGE.zh-CN.md)

让 Obsidian 中的写作、整理、同步和分享更顺手。
Simple One 将常用工具集中在一个插件里，按需开启，适应自己的笔记习惯。

## 功能特色

- **写作与排版**：快捷设置标题、引用和 Callout，按自定义规则整理笔记正文。
- **链接与网页采集**：将粘贴的网址转换为易读链接，清洗网页标题，并按自己的模板采集网页内容。
- **日历与日记**：创建日记、结转未完成任务，管理周期提醒、纪念日和假期安排。
- **阅读与显示**：调整正文宽度和图片大小，支持分列内容、图片放大，以及 HTML、颜色和图表预览。
- **附件与笔记整理**：检查闲置附件、整理文件名称与位置，过滤搜索目录，并为新笔记补齐属性。
- **笔记库同步**：电脑端全量 Git 同步提供备份与修改历史；轻量同步适配手机，也支持不安装 Git 的电脑。
- **公开笔记分享**：从现有笔记库选择内容，发布到 GitHub Pages，提供固定链接、分享管理侧栏和自定义 HTML 模板。
- **电脑端快捷工具**：快捷复制笔记链接或文件路径，让支持的弹出窗口保持在屏幕范围内。

电脑和手机的显示参数可以分别配置，设置界面使用中文。发布分享笔记需要电脑端操作，分享网站可在不同设备上浏览。

## 获取插件

在 Obsidian 第三方插件中搜索 **Simple One**，或从 [Releases](https://github.com/ZO00OEY/simple-one/releases) 下载。

安装、配置与日常操作请查看 [中文使用说明](USAGE.zh-CN.md) 或 [English user guide](USAGE.md)。
